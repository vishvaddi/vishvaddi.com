# Project Protocol

Before starting repo work, read `docs/PROJECT_STATE.md` and the latest entry in `docs/RUN_LOG.md`.

At the end of a meaningful session, update:
- `docs/PROJECT_STATE.md` with the current position and next actions.
- `docs/RUN_LOG.md` with an append-only dated entry.
- `docs/DECISIONS/` only when a real decision with alternatives was made.

Ground truth comes from code, config and git. Do not duplicate architecture or scope facts across docs; point to the authority instead.
